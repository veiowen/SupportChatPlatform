Учебный проект «Платформа поддержки» (Python, только стандартная библиотека).

Запуск из папки проекта:
python demo_generate.py
python demo_exports.py
python demo_lifecycle.py

Файлы JSON сохраняются в текущую рабочую папку.
Основной модуль: support_platform.py.
В демонстрационных скриптах: генерация 120 чатов, 5 вариантов экспорта,
жизненный цикл чата и обновление профиля.
